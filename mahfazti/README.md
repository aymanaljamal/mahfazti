# 💰 Mahfazti (محفظتي)

## Personal Expense & Financial Management Mobile Application

**Mahfazti** is a full-stack mobile personal finance application that helps users manage their personal finances by tracking expenses and income, organizing transactions into categories, setting monthly budgets, monitoring spending, receiving financial notifications, and generating detailed financial reports.

The application is built using **Flutter/Dart** for the mobile client and **Java/Spring Boot** for the backend, with **MySQL** as the development database and **JWT-based authentication** for secure API access.

---

## 📱 Overview

Mahfazti gives users a simple and practical way to understand where their money goes.

Users can:

* Record daily expenses
* Record income
* Organize expenses into categories
* Set monthly budgets
* Monitor budget usage
* Receive budget notifications
* View financial reports
* Analyze spending patterns
* Track their financial balance
* Visualize financial data through charts in the mobile application

The system follows a **client-server architecture** where the Flutter application communicates with the Spring Boot REST API using JWT authentication.

# 🎯 Budget Management

Budget management is **implemented** in the current backend.

Users can create monthly budgets for individual categories.

Each budget contains:

* Category
* Amount
* Year
* Month

The system prevents duplicate budgets for the same:

```text
User + Category + Year + Month
```

### Budget Notifications

Mahfazti automatically checks spending against the configured budget.

```text
Spending < 80%
        ↓
No warning

Spending >= 80%
        ↓
BUDGET_WARNING

Spending >= 100%
        ↓
BUDGET_EXCEEDED
```

Notifications are generated internally by the backend and stored for the user.

# 📊 Financial Reports

Reports are calculated **live from financial transaction data**.

No duplicated daily, weekly, monthly, or yearly report tables are required.

## Daily Report

Provides:

* Total income
* Total expenses
* Transaction count
* Highest expense
* Category breakdown

## Weekly Report

Provides:

* Total expenses
* Average daily spending
* Highest spending day
* Most expensive category
* Previous week total
* Percentage change from previous week

## Monthly Report

Provides:

* Total income
* Total expenses
* Remaining balance
* Average daily spending
* Category breakdown
* Previous month total
* Percentage change
* Overall budget usage

## Yearly Report

Provides:

* Total annual income
* Total annual expenses
* Monthly breakdown
* Monthly income
* Monthly expenses
* Yearly spending trend

# 📡 API Reference

Base URL:

```text
http://localhost:8080
```

Protected endpoints require:

```http
Authorization: Bearer <JWT>
```

## Authentication

| Method | Endpoint             | Description           |
| ------ | -------------------- | --------------------- |
| POST   | `/api/auth/register` | Register a new user   |
| POST   | `/api/auth/login`    | Login and receive JWT |

## User

| Method | Endpoint        | Description         |
| ------ | --------------- | ------------------- |
| GET    | `/api/users/me` | Get current user    |
| PUT    | `/api/users/me` | Update current user |

## Categories

| Method | Endpoint          | Description              |
| ------ | ----------------- | ------------------------ |
| GET    | `/api/categories` | Get available categories |

## Expenses

| Method | Endpoint                | Description       |

| POST   | `/api/expenses`         | Create expense    |

| GET    | `/api/expenses/summary` | Get expense total |
| PUT    | `/api/expenses/{id}`    | Update expense    |
| DELETE | `/api/expenses/{id}`    | Delete expense    |

## Income

| Method | Endpoint            | Description    |
| ------ | ------------------- | -------------- |
| POST   | `/api/incomes`      | Create income  |

| PUT    | `/api/incomes/{id}` | Update income  |

| Method | Endpoint            | Description    |
| ------ | ------------------- | -------------- |

# 🚀 Getting Started

## Requirements

Install:

* Java 21
* MySQL 8+
* Maven
* Git
* Flutter SDK
* Android Studio or VS Code

Check Java:

```bash
java -version
```

---

## Clone

```bash
git clone <repository-url>
cd mahfazti
```

---

## Database

Create the development database:

```sql
CREATE DATABASE mahfazti_db;
```

---

## Backend Configuration

Configure the local database connection and JWT secret.

Example:

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mahfazti_db?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true
    username: root
    password: YOUR_MYSQL_PASSWORD

  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
    open-in-view: false

server:
  port: 8080

jwt:
  secret: YOUR_JWT_SECRET
  expiration: 86400000
```

**Never commit real credentials or JWT secrets.**

---

## Run Backend

Windows:

```powershell
.\mvnw spring-boot:run
```

Linux/macOS:

```bash
./mvnw spring-boot:run
```

---

## Swagger

Open:

```text
http://localhost:8080/swagger-ui/index.html
```

---

## Run Tests

```bash
./mvnw test
```

Compile:

```bash
./mvnw clean compile
```
